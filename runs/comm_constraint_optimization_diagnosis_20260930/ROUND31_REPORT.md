### 4.2 三项限制解释规模的量化事实

1. **样本覆盖率**：一个样本是一步决策的 tape，不是一条候选消息。六条运行的全部 32 批里
   **70.4 %–96.5 % 的样本所在 tape 的候选全部被预算/容量 mask 掉**；这些样本对 actor 梯度
   贡献恒为 0，却仍在 `surrogate.mean()` 的分母里。候选级更极端：可执行候选占全部候选的
   5.4 %–7.1 %（seed11/33）与 41 %–42 %（seed22）。固定批里 `new_s22 b31` 是个内部对照：
   零梯度样本只占 10.8 %。
2. **共享主干被任务 critic 主导**：批 0 同一 minibatch 上主干 L1 中，任务 critic 项
   88.5–107.0、成本 critic 项 6.8–18.8，而 `λ·A_task` 项 1.89–7.20、`−A_cost` 项
   1.39–5.30。总 pre-clip 范数 2.39–2.69 与"两个 critic 项之和的 L2"之比达
   0.99990–1.00106，即总梯度范数几乎全部来自 critic；两项 policy 分量因近乎反向而大幅相消，
   合成后 L2 只有 0.025–0.055，熵项 0.00004–0.001。因此"主干表示主要被任务 TD 误差塑形"
   这一事实必须进入任何关于 actor 的解释。
3. **全局裁剪每批都触发**：批 0 各运行 `MAX_GRAD_NORM = 0.5` 对应缩放 ×0.186…×0.210
   （`gradient_norm_mean` 记录 1.47–1.80，同样是裁剪前尺度）。裁剪是整体等比缩放，不改变
   分量的相对比例，但它连同 Adam 的非线性意味着**梯度的分量分解不等于参数步长的分量分解**。

另有两点直接来自训练器自己的记录字段（未重算、未填零）：18 个点的
`clip_fraction ∈ {0, 0.0002, 0.0007, 0.0016, 0.0036, 0.0087, 0.0115}`、
`|approx_kl| ≤ 1.3e-03`——PPO 的信任域在这些批次里基本没有Binding，比率几乎不离开 1。
`A_combined` 的批均值从批 0 的 0.41–0.48 收敛到批 15/31 的 |·| ≤ 0.1，有效样本子集上的
批均值则在 −0.43…+0.63 之间波动（同一批内正负相抵后接近 0）。

结论：**没有发现实现或身份错误**；task 与 cost 两项信号确实进入真实 actor 更新，且方向、
量级都符合登记公式。同时不能把任何"某一项主导学习"的说法当作已证——上面的三个量化限制
正是解释的边界。

这些读数**最多**说明：在当前标量目标下、在已经观察到的这组策略上、在这份已使用过的开发数据
上，排序如何随 λ 变化。它不证明网络能到达这些策略，不证明改 λ 能解决问题，更不是最优 λ 或
部署参数；本轮未据此选择任何 λ。

## 6. 五问回答（§9）

1. **OLD/NEW 的绝对任务损失与成本处于什么水平？**
   greedy 六格里 4 格仍损失 0.5 个/ep（seed11、seed22 两臂），2 格（seed33 两臂）任务与
   immediate 相同且已计量字节更低（2 398.5 / 2 063.6 B vs 14 939.3 B，且低于 late 的
   4 838.25 B）。成本侧两极分化：seed11 两臂 ≈ 2.82 c（immediate 的 1.89 倍），seed22 两臂
   greedy 为 **0 B**（整集不发），seed33 两臂 ≈ 0.21–0.24 c。sampled 侧六个格全部既有任务
   损失（0.0625–0.4375）又普遍更贵。**"保任务"在 4/6 个 greedy 格未成立；"降成本"只在
   seed33 两臂相对两条规则同时成立，且只覆盖受控上行通道。**
2. **六条运行的约束违背与 λ 更新是否正确闭合？**
   是——192/192 批公式、配对、链、时序、checkpoint 历史五个方面全部独立重算相符，
   0 非有限值、0 版本混用、0 配对错误。同时：**违背从未反向**（`g_hat` 无一次为负），
   λ 只单调不降到 1.2375–1.5000，故"λ 按登记公式反应"已证，"约束被处理到满足"未证。
3. **实际 actor 路径是否收到登记的任务与成本信号？**
   收到。样本计数、前缀归属、优势组合、似然四类重算全部与训练器记录一致；批 0 更新起点上
   动作头只由 `λ·A_task`、`−A_cost`、熵三项驱动，前两者同量级（1.35–1.89 倍）且近乎反向
   （cos −0.73…−1.0）。范围限制见 §4.1/§4.2：只覆盖 old=new 的那个局部点、只有批 0 有权重、
   主干被任务 critic 主导、每批都触发全局裁剪。
4. **当前材料更支持哪种解释，哪些仍缺证据？**
   - **实现/身份问题**：不支持（本轮五类闭合核对全过）。
   - **有限训练内约束仍未满足**：**支持为已观测事实**（`g_hat` 恒 ≥ 0，greedy 4/6 格仍有损失）。
   - **任务/成本信号或更新尺度问题**：支持**新量化线索**——70 %–96 % 样本零 actor 梯度但仍在
     mean 分母里；主干梯度约满额来自 critic；裁剪每批把整体尺度压到 ~0.19–0.21。
     但"因此学不动"未证：这三轮里没有对该量做过干预。
   - **sampled/greedy 差异**：支持——seed33 同一 ep128 权重 sampled 读 0.25–0.4375 损失、
     greedy 读 0；seed22 训练轨迹后 8 批任务损失为 0，而 greedy 解码是 0 字节 + 0.5 损失。
     λ 跟踪的是 sampled 策略，不能转成 greedy 保证。
   - **λ 尺度是否偏低**：只有描述性线索（`s22_greedy` vs `late` 的经验交叉点 0.96765 恰在训练
     区间下沿附近）。**不足以判定 λ 太小**，也不构成调 λ 的依据。
   - **仍完全缺证据的**：追加训练能否闭合；编码替换本身是否有收益（ROUND30 已判未建立，本轮
     λ/`g_hat` 逐批相同进一步说明该改动未进入约束统计）；任何"全系统通信成本下降"。
5. **下一步最值得做的一个最小实验**：见 `ROUND31_VERDICT.json` 的
   `single_next_experiment` —— 只改 PPO surrogate 的**归约分母**（全部决策 tape → 含可执行
   候选的 tape），用以区分 H1（对偶上升在本登记尺度内太慢）与 H2（成本信号被零梯度样本稀释）。
   λ/ηλ/熵/学习率/clip/批结构/预算/场景/seed/搜索与分配 checkpoint 全部冻结；
   seed22（零梯度占比最低）作内部对照；预计 960 次环境启动（64 个 reference 可直接复用
   归档行，0 次启动）。**本轮不执行，需另行批准。**

若出现新的实际正确性错误，本轮的停止条件是"给出独立反例与影响范围后停止、不顺带修训练器"——
本轮没有触发该条件：未发现正确性错误。
