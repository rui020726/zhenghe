## 7. 明确的五项区分（授权边界 §8）

1. **系统是否可运行、可复现**：可运行、可复现。576 格全部到齐且三方账本闭合；技术门禁 8 项全通过；
   命令、冻结件、Git 外原件逐件哈希齐备（§9）。
2. **学习模型是否观察到任务损失**：是。在本块 64 个新场景上，三个 greedy 臂相对 `immediate`
   均为 −0.1719 个/集（描述性区间不含 0），逐场景 0 改善 / 54 持平 / 10 退化，且缺失的是
   11 个按时目标实例、无替换；greedy 臂的逐场景按时数与 `always_hold` 完全相同。
3. **是否比强规则更省成本**：不比强规则省。s11/s33 比 `immediate` 贵 13.5 kB/集、比
   `late_discovery_gate_147` 贵 24.7 kB/集（更贵 64/64 场景）；s22 便宜是因为它退化为从不发送。
   `late_discovery_gate_147` 以 3.4 kB/集拿到 5.8281 个/集，在本块上是成本与任务同时占优的臂。
4. **三个训练 seed 是否一致**：不一致。任务差符号一致为负，成本差符号不一致（+13.5k / −14.6k /
   +13.5k），行为定性不同（两发一静）。
5. **仍未建立的主张**：δ=0 的总体保证；跨场景块的泛化；训练算法稳定性；重复分发的幂等（真实
   数据从未出现重复发布）；事件拍无动作行与首动作前 prefix 两类契约情形在本类块中的实机覆盖；
   sampled 决策分布的不确定性（每场景一次）；"同一批丢包"意义上的逐消息配对（不成立，各臂发送
   次数不同）。
