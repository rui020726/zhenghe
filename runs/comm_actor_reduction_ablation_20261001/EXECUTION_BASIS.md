## 三、任务 B：先证明归约改变了什么

本阶段 **0 环境启动**。

### 3.1 定义两臂

两臂均使用**原 19 维期限编码**：

```text
clip(remaining_time / 50, -1, 1)
```

不混入 ROUND29/30 的新期限编码。

臂名固定：

- `ALL_ROWS`：保留当前 actor surrogate 归约；
- `ACTIVE_ROWS`：只改变 actor surrogate 的归约集合与分母。

设一个 minibatch 原本参与 surrogate 归约的记录行数为 `N`。

一行只有在保存的真实顺序 mask 路径下，至少存在一个具有策略 likelihood 权重的自由候选时，才是 active。令 active 行数为 `M`。

注意：

- 这是**记录行数**，不是环境步数，也不是候选数；
- 合法采样 HOLD 同样算自由决策；
- forced/masked 候选不能使一行变成 active；
- active 身份依据保存的已执行动作前缀确定；
- PPO 重算不能重新采样来决定 active；
- 不因一行有多个自由候选就多计行权重。

令 `s_i` 为实际实现中的逐行 clipped surrogate：

```text
ALL_ROWS:
    actor_loss = -sum(s_i) / N

ACTIVE_ROWS:
    actor_loss = -sum(s_i for active rows) / M
```

`M=0` 时，ACTIVE_ROWS 的 actor loss 为可安全反向传播的零值。

先核对真实实现是否符合上述定义；若原归约结构不同，停止报告，不自行改成另一个研究问题。

### 3.2 严格保持不变的部分

只改变 actor surrogate 的最终归约。

以下全部保持原实现：

- task/cost 优势及其归一化；
- 两个 critic 的训练样本、归约与系数；
- entropy 的归约与系数；
- λ 更新；
- PPO clipping、KL 计算及已有停止逻辑；
- minibatch 构造及顺序；
- optimizer、学习率、全局梯度裁剪；
- 网络结构、观测、mask 和环境。

不得把全 mask 行从 tape、GAE、critic 或 minibatch 中整体删除。

本轮会改变 actor 相对 entropy/critic 的更新权重，这是消融的作用范围，必须写清楚。不得宣称其他优化关系完全不受影响。

### 3.3 独立反例和接线测试

测试必须穿过实际 actor loss 路径，不能仅测试新写的均值函数。

至少覆盖：

1. **混合行反例**
   固定同一组实际输入、权重、优势和 mask。若无效行 actor 梯度为零，则在 `M>0` 时验证：
   ```text
   grad(ACTIVE_ROWS actor_loss)
   = (N/M) * grad(ALL_ROWS actor_loss)
   ```
   只比较 actor surrogate 梯度，不把 entropy、critic 或 Adam 更新混进等式。

2. **全 active**
   两种归约的 loss 和梯度一致。

3. **全 masked**
   actor surrogate 梯度为零、数值有限，critic 样本仍保留。

4. **HOLD 计数正确**
   合法选择 HOLD 的行仍计入 `M`。

5. **顺序预算 mask**
   前一候选 SEND 导致后一候选被 mask 时，active 与 likelihood 重算使用同一保存路径。

6. **补零行反例**
   仅在纯合成测试中加入 actor 零梯度行：ALL_ROWS 的 actor 梯度被缩放，ACTIVE_ROWS 不变。真实训练不得人为追加或删去行。

7. **其余损失不变**
   对相同输入和参数，entropy、两个 critic loss、优势构造及原有 KL 计算两臂一致。

8. **恢复契约**
   checkpoint 保存归约模式；不能跨归约模式静默恢复，也不能从旧轮 checkpoint 热启动。

允许最多 **64 次纯合成 optimizer 更新**检查真实更新及恢复，单独计数。其余梯度测试不需要 optimizer.step。

不要要求全 mask minibatch 后所有模型参数不变：critic、共享主干以及 optimizer 历史状态仍可能导致参数变化。

### 3.4 本阶段停止条件

出现以下情况则停止，不训练：

- 原实现与上述归约前提不一致；
- 为通过测试必须修改优势、entropy、critic 或 mask；
- 发现未解决的成本符号、GAE、奖励时序或恢复正确性错误；
- 无法隔离唯一主动改变量。
