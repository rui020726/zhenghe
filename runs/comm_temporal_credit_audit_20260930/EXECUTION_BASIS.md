## 一、项目是什么，我们要解决什么

项目是多机器人搜索与救援系统，包括：

1. **PILOC 搜索模型**：已训练，冻结；
2. **CTDE 任务分配模型**：已训练，冻结；
3. **学习型通信控制器**：针对候选消息选择 SEND/HOLD，是当前研究对象。

长期目标：

> 在保持按时完成任务数的前提下，降低已计量通信成本。

本轮不是搜索优化、任务分配优化，也不是单纯减少消息数量。

### 指标定义

- `Y`：按时任务数/episode，不是百分比或百分点。
- `C`：已计量载荷尝试字节，丢包照计费。
- 拒付的发送没有实际成本，但不能称为主动节省。
- 接收端交付条数不等于发送次数或发送成本。
- 视距感知、gossip 等旁路不在当前受控通道计量中，因此不能宣称全系统通信量下降。

### 训练目标

```text
c = C / B0
g = E[Y_reference] - E[Y_policy] - δ

L_max = -E[c] - λ_dual*g
A_actor = λ_dual*A_task - A_positive_cost

λ_dual_next = max(0, λ_dual + η_dual*g_hat)
```

已登记参数：

```text
B0 = 10000 B
δ = 0
λ_dual_initial = 1
η_dual = 0.05
```

`δ=0` 是实验期望约束，不是部署零退化保证。

务必区分：

- `λ_dual`：约束对偶变量；
- `λ_GAE`：优势估计的递推参数。

γ、`λ_GAE`、奖励时间归属和终止语义必须读取实际冻结配置，不凭本提示词猜值。

### 两种评估模式

- **greedy**：argmax，平局归 SEND；
- **sampled**：按概率采样。

它们表现差异较大。训练约束估计对应采样策略，不能搬到 greedy 上作为保证。

两臂：

- **ALL_ROWS**：actor surrogate 对原记录行平均；
- **ACTIVE_ROWS**：只对含真实自由决策的记录行平均。

两臂都使用原 19 维发送端观测，期限列仍为：

```text

```

训练 seed 为 `11、22、33`，每臂每 seed 从初值训练 128 集、32 批。

数据：

```text

开发：1301000..1301015
```

两块均已多次使用，不是独立确认集。

报告称：

- 正常环境启动 1040 次，无失败；
- actor 梯度确实按 `N/M` 放大；
- ACTIVE_ROWS 没有减少任务损失，部分 seed 明显退化；

- 任务优势幅度较大，但尚未证明它携带了正确的长期任务信用。

本轮不将 ACTIVE_ROWS 设为默认方案。

### 本轮研究问题

> 早期发送决策发生后，较晚的任务完成奖励究竟通过实际 GAE 和 critic，以什么数值信号传回该决策？

这是待检验假设，不预设“信用不足”“训练太少”或“λ 太小”为答案。
