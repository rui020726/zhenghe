## 3. 分项观察

### 3.1 A* 混合决策消融

- 关闭 A* 后 SR 从 **94.0% 降到 52.0%**（−42.0 pp），AS 从 131.1 升到 186.6，ANTO 从 5.91 降到 5.06。
- 在该论文环境里，A* 兜底不是“小幅修补”，而是决定成败的核心组件；这与新仓库中 A* 只带来 +4 pp 的结果完全不同。

### 3.2 通信丢包（c=5）

- p=0 / 0.1 / 0.3 / 0.5 时 SR = 91.6% / 91.6% / 91.6% / 92.4%，AS 133.9–135.4，ANTO 5.88–5.90。
- 干预确实生效：p=0 与 p=0.3 的逐回合比较中 **26/250 个回合的步数或成败不同**；只是聚合 SR 恰好相同。
- 通信确实发生：5 回合探测中 c=5 的同步次数为 12/0/30/0/8；c=6 时为 14/146/22/0/8。
- 结论：在 c=5 且 A* 开启时，最高 50% 的同步丢弃没有造成可测的性能退化。注意基线（第 2 节第一行）用的是仓库默认通信半径 6，因此 p=0.0 的 91.6% 与基线 94.0% 不能直接相减归因于“丢包”。

- SR 随 M 仅缓慢下降（96.0%→90.0%），ANTO/M 稳定在 0.983–0.989；AS 与覆盖率随目标数单调上升。
- 与 seeded 随机地图环境（SR 0.344→0.060）相比，论文地图上策略的目标数泛化能力强得多。

### 3.4 信息素挥发率 λ（仅推理）

- 五个点的 SR 为 92.0% / 93.6% / 94.4% / 94.0% / 93.2%，极差 2.4 pp，处于 n=250 的置信区间内。
- **λ=0.02 取得最高 SR 94.4% 与最低 AS 130.21**，与论文明确写出的 λ=0.02 一致；默认 λ=0.05 为 94.0%。
- 只能表述为“λ=0.02 附近略优”，不能声称存在显著最优值。

## 4. 未做/不适用

- **目标动态性（静态/2×）**：该环境 `step()` 没有暴露删除目标的索引，无法在不改源码的前提下精确还原静态目标；未做。
- **障碍密度、地图尺寸**：测试集是固定 60×60 图片地图，密度与尺寸不是可调参数；不适用。
- **PILOC-ph / PILOC-com 消融**：目录下存在 `Abl_del_ph`、`Abl_del_comm` 等文件夹，但本次未验证其中权重与当前入口的兼容性；未纳入。
