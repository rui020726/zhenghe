## 一、pilot 要回答的唯一问题

在部署信息路径、**真预算 binding** 的某个运行点上：
**把成本写成显式目标之后，学习型发送控制器能否在同一个额度档上 Pareto 支配一条同预算的强规则？**
两个出口都算完成（设计件 §五）。不回答的问题：λ 怎么调、观测要不要加维度、

## 二、先标定运行点，再跑任何对照（把 §11 的禁止变成程序）

`总纲 §11:1457`：**"想通过更紧 deadline 让学习策略显得有优势 ⇒ 先用真实预算检验；
新增场景须说明研究依据"**。本轮实测给了硬依据：部署 6 目标层上
A1 是 **352/352 全按时**，第十八轮 120 集里"发现但未按时"只有 **2 个** ⇒
以按时任务为约束的判据在该层**分母为空**。所以标定是必需的，不是可选的放大器。

**P1 标定规则（与任何臂的胜负无关，先登记后执行）**：
候选层阶梯 `num_goals ∈ {6, 8, 10, 12}`，其余配置一字不改（生产默认：`immediate`、
无额度、`legacy_shared_bound`、`gossip_interval=2`、`comm_range=0.3`、`deadline_tightness` 默认带）。
每层 30 个**新** seed × 2 臂（`immediate`、`always_hold`）。
选**第一个同时满足**下列两条的层，按阶梯顺序，不得回头挑"更好看"的层：

| 条件 | 阈值 | 为什么 |
|---|---|---|
| K1 约束有分母 | `immediate` 层的"发现但未按时" ≥ **0.50 个/ep** | 少于这个数，任何效果约束都近似自动成立 |
| K2 通信仍有价值 | `immediate − always_hold` 按时差 ≥ **0.30 个/ep** 且配对 95 % CI 下界 > 0 | 差为 0 说明旁路把上行完全旁掉了，降本无从谈成本效果 |
| K3 额度真 binding | 后续 P3 中该层 `immediate` 在选定额度档上 `budget_refused_sends > 0` | 不 binding 的档第十五轮已证明等于没约束（75 % 档额度使用仅 0.40–0.45） |

四条阶梯都不满足 ⇒ **判"该轴在部署路径上不可测"，直接停止并交付**（不新增场景、不改 deadline 带、
不加机器人数）。这是一次合格交付，不是失败。

## 三、臂与额度档（P3 正式矩阵）

| 臂 | 选择方式 | 额度 | 备注 |
|---|---|---|---|
| `always_hold` | 已有规则 | 无额度（它自己发 0 B） | 地板，K2 用它 |
| `immediate` | 已有规则（生产默认） | 3 档 | 现状参照；也是"上限参考"的候选 |
| **`late_only(ĉ)`** | **P0 新实现的最小规则臂** | 3 档 | 只在 `step > ĉ` 报首报；ĉ 在**开发段**选，正式段只用这一个值 |
| `learned` ×3 训练 seed | 已有 `--comm-policy learned` + `attach_policy` | 3 档 | 从初值训，3 seed 全部单独报告，不得只展示最好一次（§10:1441） |
| `event_unbudgeted`（可选上限参考） | 已有 | **无额度** | 只作参考，不参与"同预算公平"要求（§8.1:1227 例外条款） |

**额度档定义（先算后跑，不看完结果再挑）**：以 P1 标定层上 `immediate` 的实测均值
`B̄ = E[airtime_bytes]` 为标尺，取 **{0.15 B̄, 0.30 B̄, 0.60 B̄}** 三档。
依据：本轮测得部署路径**只有首报、无刷新**（`refresh_emissions` = 0，`emissions` = 发现数），
所以一份报告就是 2 484 B 量级的整数份 ⇒ 高百分位档必然不 binding（第十五轮 75 % 档的教训），
必须把档压到"报告份数"这个粒度以下。若三档全不 binding ⇒ 触发 §二 K3 的停止分支。

## 四、容忍度与判据（预登记，单位一律写明）

| 编号 | 判据 | 单位与口径 |
|---|---|---|
| **J1 主判据（出口 P）** | 同一额度档、同一 seed 集上：`learned − late_only` 的按时差配对 95 % CI 上界 **< +δ**，**且**字节差配对 CI 上界 **< 0 B** | 按时：**个/episode**；字节：**B/episode**（只取 policy 归因 attempts，`budget_refused_sends`/`capacity_refused_sends` 单列）。两式同时成立才算支配 |
| **J2 非劣容忍度 δ** | **δ = 0.10 个/episode**（60 seed 批 = 6 个任务） | 依据：本轮实测的通信价值 C1 = 0.31667 个/ep、CI [0.18333, 0.45] ⇒ δ 取约其 1/3，且必须小于"通信本身的价值"，否则约束形同放弃通信 |
| **J3 出口 N** | J1 不成立，且 `late_only` 相对 `immediate` 在任一档同时给出"字节更少、按时差不劣于 −δ" | 判"成本目标显式化后，同预算规则已吃满该档" ⇒ 正常交付，不得外推为"学习普遍无效" |
| **J4 降本单价** | 只在两臂字节不同时报 `Δ字节 / Δ按时`（B / 个/episode） | 本轮已实测该比率的两个端点：46 020.9 B/个（A1 vs A2）、第十八轮 2 490.7 B/按时任务。**同一批字节的两臂不得报此量**（C2 教训：计费字节相同就不存在降本） |
| **J5 效果守卫** | `expired` 个/episode 与"逐目标新增失败数"必须逐 seed 全列 | 分母不同的量不得相加（个/ep 与个/批不混；任务级 ≠ 目标级） |
| **J6 统计口径** | 按 seed 配对、百分位 bootstrap **B = 10 000**、RNG 登记（沿用 `20260923`/`20260925` 之后的新注册值） | 与第十/十六/十八轮同一统计对象，便于横向引用 |
| **J7 随机性登记** | 明文登记：策略改变发射序列就改变信道随机数消费 ⇒ 只主张共享初始场景与 seed 的配对比较，不主张后续逐位相同 | 第十八轮同款条款 |

**判据冻结**：本文件四张表在 P0 之前单独提交；冻结后不得因中间结果换策略、换 seed、
改终止条件或追加样本。
