# 一页决策摘要（第十九轮设计修订）

**推荐方案（一句话）**：把已计量的载荷尝试成本写成**被优化的目标**，把任务效果写成**相对固定参考策略的损失约束**，
用**带对偶变量 λ 的约束式策略梯度**实现——actor、观测、动作、mask、计费单点、协议、默认值**全部不动**，
新增的只有一个 cost critic 头、一个标量 λ 更新和一套配对约束估计；**不需要额度 binding，不需要新场景，不需要 λ 系数标定**。

```text
最小化  E[已计量载荷尝试成本(π)]                      单位 B/episode（只取 policy 归因 attempts）
约束    E[按时(ref)] − E[按时(π)] ≤ δ                  单位 个/episode；ref 固定 = immediate（生产默认）
判定    约束成立 = 配对 bootstrap CI 上界 ≤ δ           B = 10 000，RNG 注册；λ 只驱动训练，不替代判定
预算    仍是硬执行栏杆（丢包照付、拒付不计费），不承担"最小化成本"
```

**与旧训练的确切区别**：旧的目标只有按时完成，字节仅是硬额度与事后计数 ⇒ **成本没有梯度**；
新目标里成本有梯度，且 λ 由**测得的约束违背**更新（不是手挑系数，因此不触犯 N4
"不得用未通过门槛的层去挑成本系数"）。旧件"先有 ≥3 个 binding 内点"的前置**已删除**：
在对偶路线里成本水平是训练的**输出**，前沿是产物不是输入。

**已更正的解释**（旧件保留不改，修订独立提交）：三桶标签改为**整策略对照下的描述性**名称
（`outcome_differs_under_full_silence` 19 / `known_no_later_and_outcome_same…` 110 /
`known_later_but_outcome_same…` 223；合计 352，字节 47 706 + 273 162 + 553 530 = 874 398 B）；
**目标份额 5.40 % / 31.25 % / 63.35 %（÷352）与字节份额 5.46 % / 31.24 % / 63.30 %（÷874 398 B）不得混写**；
AUC 0.9174 与阈值 ĉ = 147 标为**开发集探索性结果**（无划分、无拟合、阈值与标签同批数据）；
`late_only` 明确为**"晚发现才发送"（门控）**、不是"延迟已有信息"（推迟），改名 `late_discovery_gate(ĉ)`；
费用一律称**载荷尝试成本（当前计费模型口径）**，gossip/视距刷新/ACK/轮询等未计量项继续单列。

**待批准参数（全部仍是建议值）**

| 参数 | 建议 | 备注 |
|---|---|---|
| δ（按时损失容忍度） | **0.10 个/episode** | 需 n = 120 配对 seed 才可在 L≈0.05 时判定；若接受 **δ = 0.15**，n = 60 即可 |
| 降本门槛 | **成本差配对 CI 上界 < 0 B** | 不设百分比门槛，避免把"少发"当"省" |
| 训练量 | **3 seed × ≤ 400k = ≤ 1.2M 步** | 与第十轮同档，**不得追加** |
| 参考策略 ref | **`immediate`**（生产默认） | 评估期内固定不换 |
| λ 超参 | `η_λ`、`λ_max` 在跑前冻结并写入运行身份 | 轨迹逐批次落盘、逐 seed 报告 |
| 规则臂 `late_discovery_gate(ĉ)` | **暂不实现**（未获批准） | 只是新候选对照；**不代表学习可行性已建立**；ĉ 须在跑新 seed 前冻结 |
| seed | B 阶段 2 个、C 阶段 120 个，**均取新段**（提议 `1300000..1300001` / `1300100..1300219`） | 先做碰撞审计；若已被使用 ⇒ 停，不自行改号 |
| 额度档 | **不设**（推荐路线不需要） | 额度扫描只作备选，回退需再批准 |
